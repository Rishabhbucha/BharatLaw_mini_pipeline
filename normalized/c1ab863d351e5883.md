# Screen Reader

## Screen Reader Access

The Income Tax Department’s website conforms to the GIGW 3.0. This ensures that persons with visual impairments can easily access the site using assistive tools such as screen readers. All content on the website is designed to be compatible with a variety of screen readers. Following are the list of popular screen reader.
